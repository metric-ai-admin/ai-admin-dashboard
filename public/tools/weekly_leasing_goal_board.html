Funnel & quality boards
Leasing vocabulary & how to read the board
Traffic
Guest cards generated for the property in a given week.
Follow-Up Calls
5× traffic — a calculated outreach-volume estimate, not a logged call count. No real call-log data source is used anywhere on this board.
Tours
Same event as a completed Showing in AppFolio. Default goal is 25% of traffic (editable via the Traffic → Tour slider); actuals are pulled directly from completed showings.
Applications
Move-ins × 1.15 to cover cancellation/denial benchmarks; also = 80% of tours by default (editable via the Tour → Application slider).
Move-Ins
Completed leases that physically move in.
Lead→Lease
Approved applications ÷ trailing-12-month guest cards — conversion efficiency.
Cancellations
Goal <5% of applications.
Denials
Goal ~10% of applications.
Maintain
Already at/above occupancy goal with ≤1 net move-in needed.
High-Volume Traffic Not Converting
Projected pace meets/exceeds the traffic target but occupancy is still below goal.
Low Conversion
Lead→lease conversion (or portfolio rate, when thin) is below the 10% benchmark.
Low Traffic
None of the above — traffic volume itself is the binding constraint.
Slow Application Processing
Cancellation rate ≥10% of applications, flagged separately from the primary diagnosis.
* thin data
Fewer than 10 applications or a lead→lease rate under 6% — diagnostics fall back to the portfolio conversion rate when enabled.
Call Volume Standard
Minimum outbound calls per week = 3 × active prospects (approximated as trailing 90-day guest cards). Shown per property; real call counts are logged in AppFolio, not this board.
Application Processing SLA
3 business days to decide an application. The Slow Application Processing tag's hover list flags any pending application past this SLA.
